# scripting-produktmetodik 

## Product Vision

Vi ska skapa ett PowerShell script för att spara energi och inventera vårt nätverk. Syftet är att minska onödig energiförbrukning genom att identifiera datorer som är påslagna men inaktiva, logga informationen och vid behov schemalägga viloläge eller avstängning.


## Viktigaste funktioner

- Inventera en eller flera datorer 
- Identifiera datorer som verkar inaktiva
- Logga inventering och åtgärder till loggfil
- Möjlighet att stänga av eller försätta datorn i viloläge
- Enkel demo som visar att lösningen fungerar


## Scrum och arbetsmetod

Projektet genomförs med korta 1 dags sprintar enligt en anpassad Scrum. Varje sprint innehåller planering, genomförande och review.
Arbetet hanteras i GitHub Projects där varje uppgift ska kopplas till en user story eller issue. Kort flyttas mellan To Do, In Progress och Done under arbetets gång.
